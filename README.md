# The One-Line Laugh

One funny line, written by `main.ts` (Node 22, standard library only) to
`/output/entry.txt`.

The line is a single sentence, under 200 characters: a dog who learned to
open the treat cupboard now waits by it every morning like a landlord
collecting rent. Everyday truth, surprise saved for the end, no explanation.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory (or `OUT_DIR`,
or it defaults to `/output`).
